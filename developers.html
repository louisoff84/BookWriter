Vue d’ensemble

Toutes les réponses API sont en JSON. Les routes privées utilisent un Bearer token. Le frontend est hébergé séparément sur GitHub Pages.

POST/auth/login

Authentification

Le frontend utilise un token temporaire bwa_…. Pour vos intégrations, créez une clé bw_… depuis votre compte.

Authorization: Bearer bw_votre_cle_api
GET/books
POST/books
PATCH/books/{id}
DELETE/books/{id}

Gérer vos livres

{
  "title": "Mon livre",
  "description": "Une aventure...",
  "category": "fantasy",
  "content": "Chapitre 1..."
}

Publier : POST /books/{id}/publish. Dépublier : POST /books/{id}/unpublish.

GET/public/books

Bibliothèque publique

Paramètres disponibles : search, category, limit et offset.

GET /public/books?category=fantasy&search=dragon
